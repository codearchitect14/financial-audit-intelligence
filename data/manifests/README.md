# Manifests

Hand-reviewed inputs that cannot be regenerated by a script. These **are**
tracked in git; everything else under `data/` is not.

## `aaer_cik_map.csv`

Maps SEC Accounting and Auditing Enforcement Releases to filer CIKs and the
period each enforcement action covers.

| Column | Meaning |
|---|---|
| `cik` | Filer CIK, zero-padded to 10 digits |
| `company_name` | Registrant name as it appears in the release |
| `violation_start` | First day of the misstatement period, `YYYY-MM-DD` |
| `violation_end` | Last day of the misstatement period, `YYYY-MM-DD` |
| `aaer_number` | Release identifier, for traceability back to the source |
| `match_confidence` | 0.0 to 1.0. Rows below 0.90 are ignored at load time |

The period columns are not optional decoration. A company named in an AAER was
not fraudulent in every year it filed, and only filings whose period end falls
inside the window are labelled positive. See
[docs/data-pipeline.md](../../docs/data-pipeline.md).

**The two rows currently in this file are format examples, not research
output.** Replace them with reviewed matches before training any model on the
labels. A mislabelled row is worse than an unlabelled one.
